**提示词附加规则要点**（原文见 `docs/prompts/system-after-p0.4.txt` 末尾）：

1. 生图不用 `comfyui_generate`，改 `comfyui_task_submit`
2. 每次用户主动请求生成新的 `idempotency_key`；同一逻辑请求重试复用同一个 key
3. submit 超时未拿到 task_id 时，只能用**原幂等键**重试
4. 轮询 5–10 秒、最多 60 次
5. 状态映射：pending/running→继续等；completed→交付；failed→报 error_code；
   cancelled→如实说取消；submission_unknown→结果不确定，禁止自动重提
6. 轮询耗尽：停止轮询、告知“仍在后台执行”并给 task_id；**不得当失败、不得取消任务**
7. 失败/取消不得退回同步 `comfyui_generate`

## 2. 工具调用路径：改前 vs 改后

**改前（同步阻塞）**
```
用户请求 → comfyui_generate ──submit+等待到出图（90~300s）──→ 返回结果
             ↑ 单次工具调用全程占用 LangBot blocking executor
```

**改后（异步）**
```
用户请求 → comfyui_task_submit（~300ms）→ task_id
         → comfyui_task_status（每 1~10s，最多 60 次）
         → completed → 读取 result → 交付图片
```

实测调用序列（run 29，01:32–01:38）：

```
comfyui_list_models ×1        (83ms)
comfyui_task_submit ×1        (58ms)   ← 无阻塞
comfyui_task_status ×40+      (20~500ms)
comfyui_queue_status ×2       (辅助，非必要)
→ run completed，回复含 Image 段
```

**全程未出现 `comfyui_generate`。**
