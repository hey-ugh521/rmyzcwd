# M2 实施计划 — Provider Adapter + 媒体资源调度

> 依据：`docs/adr/ADR-008-media-provider-resource.md`（Proposed）
> 前置：main `29b6f82`（M1 完成、生产已部署）
> 原则：先设计确认，再改代码；每阶段可独立回滚，外部 API 不变

## 1. 目标

- Gateway 内部建立 `MediaProvider` 契约 + Registry；ComfyUI/TTS 变成可替换 Adapter。
- 引入显式资源调度（GPU heavy 独占、CPU TTS 共享、lease/队列/回收），消除 TTS 与生图抢 GPU 的隐式风险。
- Core 只消费能力/健康摘要与任务状态；Provider 细节不出 Gateway。
- 保持 `/api/*`、MCP、M1 任务 owner 契约兼容；用 `MOBIUS_MEDIA_PROVIDER=legacy|adapters` 回滚。

## 2. 阶段与交付

### M2a — 契约 + Registry + ComfyUI Adapter（✅ 已完成 2026-11-10，legacy 默认）

文件（建议）：
- `media_gateway/providers/base.py`（Protocol/数据类/错误）
- `media_gateway/providers/registry.py`
- `media_gateway/providers/comfyui.py`（包装现有 submit/poll/cancel）
- `media_gateway/server.py`（开关；`/api/providers` 只读）

内容：
- ProviderCapabilities/ProviderRequest/Submission/Execution/CancelResult/Health 数据类。
- Registry 从 config `media.providers/routing` 构建；能力校验；Provider 特定字段不外泄。
- ComfyUI Adapter 复用现有 HTTP/轮询/恢复逻辑，行为与 legacy 一致。
- 特性开关；legacy 路径保持默认。

验收：✅ 契约测试 23/23；既有网关回归全过（t5/t3/t4/async）。
- 契约测试（mock HTTP）覆盖 health/capabilities/submit/query/cancel/超时/不可用。
- legacy vs adapters 同一请求的 task_id/状态/结果一致（图片路径、取消、恢复）。
- Core grep 不到 ComfyUI 字段；`/api/providers` 只读返回能力/健康。

### M2b — TTS Adapter + 能力路由（✅ 已完成 2026-11-10，legacy 默认）

文件：
- `media_gateway/providers/kokoro.py`、`gsv.py`、`f5.py`（可选）
- `media_gateway/server.py` 的 `synth_tts`/`do_tts` 接入 Registry

内容：
- engine→Provider 映射；能力（tts/voice_clone）校验；健康回退链；业务错误不回退。
- 返回结构、文件命名、时长/字节限制与 legacy 一致。

验收：✅ TTS Provider 契约/回退 17/17；adapters 路径落盘冒烟通过；既有网关回归全过。
- Kokoro/GSV/F5 契约测试；不可用时正确回退/失败；角色/文本校验不变。
- legacy vs adapters 音频结果（wav/路径/元数据）兼容。

### M2c — 资源调度器 + 租约

文件：
- `media_gateway/providers/resources.py`（或 `media_gateway/runtime/resources.py`）
- `media_gateway/server.py` worker/submit/cancel/recovery 接入
- `core/services.py` idle 判断读取 Runtime lease 摘要（替代纯启发式）

内容：
- `gpu_heavy` 独占、`cpu` 共享（可配 max_concurrency）；FIFO + 公平队列。
- acquire/release；lease owner/expiry；取消/异常/崩溃回收。
- Provider 不支持取消时如实上报；Core 终态策略不变。
- Core idle 休眠前置条件：无 heavy lease/queue；prewarm/on_demand 语义不变。
- `/api/pulse` 或 `/api/providers` 暴露 lease/queue 摘要（内部）。

验收：
- 单测：并发提交只允许一个 GPU heavy；CPU 并发上限；排队/公平；取消/异常释放；租约过期回收。
- 集成：ComfyUI 生图 + GSV TTS 同时请求不并发 GPU；Kokoro 不阻塞生图。
- 故障注入：Provider 挂、超时、进程崩溃后无永久 busy lease。

### M2d — Core 集成 + 文档 + 切换默认

内容：
- Core 能力/健康只读（可经 Gateway `/api/providers`）；Console 诊断展示（可选）。
- 更新 ADR-008 实现状态、ARCHITECTURE-GAP、STATUS；补 M2 契约测试。
- 验收通过后默认 `adapters`，保留回滚开关一个 release；重建安装器/发布。

验收：
- M1 全量回归通过；外部 REST/MCP 不变；`MOBIUS_MEDIA_PROVIDER=legacy` 可回退。
- 生产部署演练：备份 → 部署 → 观察 → 回滚路径验证。

## 3. 测试清单（必须）

- `tests/test_m2_provider_contract.py`（契约/能力/错误映射）
- `tests/test_m2_comfyui_provider.py`（mock ComfyUI）
- `tests/test_m2_tts_providers.py`（Kokoro/GSV/F5 + 回退）

## 4. 边界

- 不做：第三方 Provider 插件市场、多 GPU、跨机调度、模型下载、桌面 UI 改造。
- 不改：LangBot/NapCat、MCP 工具名与响应结构、Core 任务 owner 语义。
- 不碰生产实例；测试用临时端口/临时 DB/mock Provider。
