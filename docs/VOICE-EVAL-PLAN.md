# 语音（角色 TTS）评测计划：音色 / 韵律 / 情绪解耦

> 2026-11-05。目标类型 = **B：角色语音引擎**（文本 + 情绪/语气/语境 → 符合角色身份的语音，供 AI 助手实时调用）。
> 原则：**先评测、后重训/换模**；不接受"只凭听感"的结论。

---

## 1. 当前实际配置（回答评估问题）

| 项 | 现状 |
|---|---|
| 模型 | **GPT-SoVITS v4**（整合包 `GPT-SoVITS-v4-20250529-nvidia50`），非 v2pro |
| 训练流程 | 预处理：1-text(BERT) / 2-hubert(32k) / 3-semantic(25Hz)；s1 20 epochs（s1v3 预训练）；s2 **V4 LoRA rank32**（s2_train_v3_lora.py），6→12 epochs，batch 2–4 + grad checkpoint |
| 推理 | **fp32**（fp16 有发闷/金属伪影）；GPT=微调 teresa4-e20；SoVITS=**v4 基座**（弃用 LoRA）；输出 48kHz |
| 硬件 | RTX 5060 Laptop，**8GB 显存**；PyTorch 2.7.0+cu128 |
| 数据 | **253 条 / 10.89 分钟**德丽莎中文语音（2–10s，单一 CV，无学园长/月下等版本） |
| 交付 | QQ 语音条（`tts_speak`），无情绪控制参数 |
| 备选 | IndexTTS-2.5 已安装（`D:\AI\IndexTTS-bundle`）；8GB 需 `use_qwen_emo=False`；输出 22.05kHz |

已知问题（与用户分析一致）：
1. 音色"像但不够稳"；
2. 无情绪控制；参考音驱动的韵律不可控；
3. LoRA 微调反而降低清晰度/音色稳定性（训练在混合情绪短句上）。

## 2. 评测路径

| 步骤 | 内容 | 产出 |
|---|---|---|
| S1 | **数据审计 + 情绪分层**：用 emotion2vec 自动标注 253 条情绪；统计分布；划分「核心音色集 / 情绪集 / 特殊集」；另留 10 条未见文本作泛化测试 | 数据集报告 + 分层清单 |
| S2 | **评测框架**：固定文本集（10 条，含未见文本）× 情绪模板（平静/开心/生气/悲伤）；输出指标：说话人相似度（CAM++ 对德丽莎参考）、F0 范围、语速、情绪分类准确率（emotion2vec）、泛化 WER（whisper） | `ops/voice_eval/` 脚本 + CSV/报告 |
| S3 | **基线**：GPT-SoVITS v4 fp32（当前生产）；情绪通过"对应情绪的参考音"驱动（GPT-SoVITS 不支持情绪向量） | 基线指标 |
| S4 | **IndexTTS-2.5**：emo_vector / emo_audio 两条路径，同套指标 | 指标 |
| S5 | 可选 **CosyVoice3**：先评估安装成本/显存占用，若 S3/S4 差距明显且你同意再装 | 决策 |
| S6 | **结论 + 样音矩阵**：给出「音色稳定性 vs 情绪准确率」对比表与推荐 | 报告 |

---

## 3. 验收标准

| # | 标准 |
|---|---|
| A1 | 评测脚本可复现（一条命令跑完，输出 CSV + Markdown 报告） |
| A2 | 每个方案 × 4 情绪各 ≥3 条样音，记录 speaker similarity / F0 / 情绪分类 |
| A3 | 同一文本在 4 情绪下：**说话人相似度波动 σ ≤ 0.05**（可调），且情绪分类准确率 ≥ 70% |
| A4 | 10 条未见文本全部生成成功，WER 可量化 |
| A5 | 结论表 + 推荐方案（保留 GPT-SoVITS / 切换 IndexTTS / 重训数据），经你确认后执行生产切换 |
